agent-authCredentials for AI agents that you can scope, expire, revoke and audit

A small self-hosted service, CLI and TypeScript SDK. Give an agent exactly the authority a task needs, and see everything it did with it.

Quickstart
Concepts

Narrow scopes

Scopes name actions, resources, parameters and spend limits, such as gmail:send to:*@acme.com or payments:charge max=50USD.

Attenuation for sub-agents

An agent can hand a sub-agent a narrower token. The service proves the child is no broader than its parent.

Revocation that cascades

Revoking a token cuts off everything derived from it. Tokens also expire and can carry use limits.

Human approval

Mark risky scopes approval=required, and each use waits for a person to approve that exact request.

Tamper-evident audit log

Every decision lands in a hash-chained log. agent-auth audit verify finds the first altered entry.

One npm package

The CLI, the server and the TypeScript SDK install together with npm.
